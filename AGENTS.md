# BookWeaver — общие правила репозитория

- **Язык общения:** русский, ответы лаконичные и по существу.
- **Комментарии в коде:** писать самодокументируемый код; комментарии допускаются только для объяснения сложной бизнес-логики, хаков или нетривиальных архитектурных решений.
- **Строгая типизация:** обязательные type hints в Python и строгие типы без `any` в TypeScript.

## Структура и вложенные правила
- `backend/` — Python, FastAPI, SQLModel, AI-пайплайны (см. `backend/AGENTS.md`).
- `frontend/` — React, TypeScript, Material Design 3 Expressive (см. `frontend/AGENTS.md`).
