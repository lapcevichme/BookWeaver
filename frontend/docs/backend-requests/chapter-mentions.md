# Backend Request: Точная разметка упоминаний персонажей в тексте главы (v2)

- **Связанная фича в бэклоге:** `F-10` (Кликабельные имена в тексте читалки)
- **Статус:** `requested`
- **Дата:** 2026-11-22

## 1. Суть и зачем нужно
Сейчас v1 подсветки имён в читалке работает на фронте через матчер `name` + `aliases` из `characters/as-of` с базовой поддержкой русских падежей. Для точного снятия неоднозначности ролей («Доктор», «Император») и сложной морфологии в будущем полезно отдавать точные оффсеты упоминаний с бэкенда.

## 2. Предлагаемый контракт API

### Расширение `GET /api/v1/projects/{book_name}/chapters/{chapter_id}/text`

Опциональное поле `mentions` в ответе:
```json
{
  "chapter_id": "vol_1_chap_6",
  "text": "...",
  "mentions": [
    { "start": 42, "end": 48, "character_id": "09d0cd10-..." }
  ]
}
```

## 3. Антиспойлерные правила
- `character_id` указывает на запись персонажа, известную читателю в этой главе (до `revealed_in` — на маску/персону, а не на скрытую истинную личность).
