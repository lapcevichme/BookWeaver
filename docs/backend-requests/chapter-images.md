# Backend Request: Отдача иллюстраций глав для Читалки

- **Связанная фича в бэклоге:** `F-08` (Читалка)
- **Статус:** `implemented`
- **Дата:** 2026-11-22

## 1. Суть и зачем нужно
В тексте глав ранобэ встречаются Markdown-вставки `![Иллюстрация](../images/img_687a2e4816.jpg)`. Чтобы читалка рендерила настоящие иллюстрации вместо текстовой заглушки, нужен безопасный эндпоинт отдачи картинок книги.

## 2. Предлагаемый контракт API

### `GET /api/v1/projects/{book_name}/images/{filename}`

**Path параметры:**
- `book_name` (`string`) — ID книги.
- `filename` (`string`) — имя файла без подпутей (например, `img_687a2e4816.jpg`).

**Ответ (`200 OK`):** бинарный файл изображения (`FileResponse`).
**Ошибки:** `400` при попытке path traversal, `404` если файл не найден.
