# Связи личностей (`IdentityLink`)

**Дата:** 2026-11-12
**Статус:** концепт, не реализовано
**Связано:** `docs/experiments/2026-11-12_speakers-casting.md` (связи подписей), `2026-11-06_character-patch.md` (почему не векторное слияние)

## Задача

Один человек в книге бывает двумя персонажами: маскировка (Шисуй = Лоулань, раскрытие — по памяти автора, около 5 тома), чужое тело (Вэй Усянь в теле Мо Сюаньюя в «Магистре дьявольского культа»), самозванец, дубль из-за смены имени. Сейчас этого не видно нигде:

- `SpeakerLink` связывает **подпись** («Красавец-евнух», гл. 4) с персонажем, а не персонажа с персонажем. `identity_hidden` есть только там.
- Шисуй придет из анализа персонажей отдельным `Character` с собственным именем — у ее реплик будет `speaker_id`, этап `speakers` их не увидит.
- Слияние персонажей — не ответ: это не дубль, а раскрытие. Слияние стирает историю и спойлерит. Векторное слияние на Кусурии дало 7 ложных пар из 7 (Линли/Гёкуё 0.83 и т. д.).

## Модель

```
IdentityLink
  id
  persona_id      → Character   # кем персонаж выступает (Шисуй)
  true_id         → Character   # кто это на самом деле (Лоулань)
  relation        same_person | impersonation | possession | duplicate
  revealed_in     chapter_id?   # глава, где узнает ЧИТАТЕЛЬ; пусто — подозрение без раскрытия
  confidence      high | medium | low
  evidence        текст с номерами глав
  status          suggested | confirmed | rejected
  voice_policy    separate | shared | switch_after_reveal
  source          patch | scan | human
```

- **Персонажи не сливаются.** Сценарий, `speaker_id`, описания по главам — без изменений. Связь — отдельный слой поверх.
- `relation`:
  - `same_person` — маскировка, второе имя, о котором читатель не знает;
  - `impersonation` — B выдает себя за A (реплики «A» говорит B);
  - `possession` — душа одного в теле другого; читатель может знать с первой главы;
  - `duplicate` — один человек дважды заведен анализом персонажей (вместо автослияния: предложение «слить»).
- `voice_policy` — решает человек, по умолчанию `separate`:
  - `separate` — у каждой личности свой голос, переозвучка не нужна (так часто делает живой чтец);
  - `shared` — один голос везде; уже озвученные главы персоны помечаются на переозвучку, голос раскрывает тайну раньше текста;
  - `switch_after_reveal` — до `revealed_in` голос персоны, с нее — голос истинной личности.

## Где применяется

- **Голос:** `resolve_voice` после `speaker_id` и `SpeakerLink` смотрит подтвержденные `IdentityLink` с учетом главы и `voice_policy`. Цепочки (A = B, B = C) разворачиваются до конца.
- **Спойлеры:** API `asOfChapter` и описания показывают связь только начиная с `revealed_in`. Неподтвержденные и нераскрытые связи — только в CLI автора.
- **Переозвучка:** смена политики не перегенерирует аудио сама; `inspect` показывает «N реплик в M главах озвучены не тем голосом».

## Как находить

1. **В патче персонажей, без нового вызова.** Патч уже видит справочник всех персонажей. Добавить необязательное поле `same_as: {ref, revealed, evidence}` — модель ставит его, когда текст главы прямо говорит «X — это Y». Это ловит раскрытие в момент раскрытия, то есть главный случай.
2. **Проход в конце тома (подозрения).** Кандидаты пар — дешевыми сигналами, решение — LLM по пересказам:
   - векторное сходство описаний — только как фильтр (ловит тему, а не личность);
   - **не встречаются в одной сцене**: два частых персонажа, которые ни разу не говорят в одной главе, — классический признак маски. Считается по сценарию без LLM. Гипотеза, проверить на длинном прогоне.
3. **Человек:** `identity link <A> <B> --relation ... --revealed-in ...`.

## CLI

`identity list|suggest|confirm|reject|policy`, `inspect identities` (связи, доводы, сколько реплик затронет политика).

## Риски

- **Ложный след.** Автор нарочно ведет читателя к неверной догадке; LLM подхватит. Поэтому только предложение, а `confirmed` без `revealed_in` голос не меняет.
- **Раскрытие внутри главы.** Первая версия считает по главам; переключение с конкретной реплики — потом.
- **Читатель знает, герои нет** (`possession`): сценарий подписывает реплики «Мо Сюаньюй», хотя говорит Вэй Усянь. Нужна проверка на живом тексте.
- **Книга дописывается частями.** Связь, найденная в 5 томе, касается глав 1–4, уже обработанных раньше. Без пересмотра старых глав (см. `docs/backlog.md`, «Долгий прогон») связь не применится.

## Как проверить

- Кусурия, тома 1–4 (в `parsers/…ln-novel [165329]`: 117 файлов, ~3.1 МБ): длинная дистанция, накопление персонажей, межтомовая память. Раскрытие Шисуй, вероятно, дальше — нужен 5 том.
- «Магистр дьявольского культа» (`input/books/magistr_dyavolskogo_kulta`): `possession` с первых глав, читатель знает — проверка без ожидания раскрытия.
- Короткий детектив с маскировкой — `same_person` с раскрытием в конце на малом объеме.
